# gemóvel - integrative-project
A system for managing short-term rentals and administering properties

Sistema de gestão de imóveis de temporada. Projeto integrado do Técnico em Informática, turma 2 TID: Arthur Gazzoli e Washington.

## Ver o site pronto

- **No computador:** dois cliques em `Abrir o site.bat`, na pasta do projeto. O site abre no navegador, com os dados de exemplo, sem Flask e sem MySQL; para desligar, feche a janela preta.
- **Na internet:** depois de ligar o GitHub Pages uma vez (Settings → Pages → Source: GitHub Actions), o site fica em https://washington-dev-fullstack.github.io/gemovel-integrative-project/.

## Onde está cada coisa

| Pasta | O que tem |
|---|---|
| `site/` | o site pronto, que vai para o GitHub Pages (é gerado: não edite à mão) |
| `frontend/` | as telas do sistema: páginas, CSS e JavaScript |
| `backend/` | a API em Flask (Python) e os testes dela |
| `banco/` | o SQL do banco, os dados de exemplo, os diagramas e o PDF das modelagens |
| `design/` | as telas e os componentes aprovados; o sistema de design está no `DESIGN.md` |
| `docs/` | os documentos da escola, as especificações e os planos |
| `ferramentas/` | o gerador da pasta `site/` e o programa que o `Abrir o site.bat` roda |
